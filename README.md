
# Coffee Rock ☕

A modern coffee shop Point of Sale (POS) application built with **Flutter and Dart**, designed for Android tablets.

Coffee Rock aims to provide coffee shop staff with an intuitive interface for managing products, customizing drinks, handling orders, and processing checkout.

## ✨ Features

- Tablet-first POS interface
- Product catalog and categories
- Shopping cart and quantity controls
- Drink customization (size, sugar, milk, and toppings)
- Automatic subtotal and total calculations
- Checkout and payment workflow
- Local database for offline data storage
- Order history and receipt management

*Features are subject to implementation progress.*

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Riverpod
- **Architecture:** MVVM + Clean Architecture
- **Database:** Drift + SQLite
- **Target Platform:** Android tablets

## 🎨 Design

Coffee Rock features a warm, coffee-inspired design using espresso brown, cream, caramel, and beige.

The interface is optimized for landscape orientation on medium-sized Android tablets.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or another supported Flutter development environment
- Android emulator or physical Android device

### Installation

1. Clone this repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd <YOUR_PROJECT_DIRECTORY>
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## 🧪 Testing

Run automated tests with:

```bash
flutter test
```
